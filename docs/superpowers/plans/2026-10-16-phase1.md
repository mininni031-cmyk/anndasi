# PATTERN LAB Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** CSVからローソク足と過去類似上位5件を確認できるローカルアプリ。
**Architecture:** Next.js client UI、純粋TypeScript解析、Worker検索、IndexedDB保存を分離する。
**Tech Stack:** Next.js / React / TypeScript / Tailwind / Lightweight Charts / Vitest / Playwright
**Spec:** docs/superpowers/specs/2026-10-16-pattern-lab-phase1-design.md

## Global Constraints
- 無料構成。実注文・外部API・外部送信なし。
- CSV: time,open,high,low,close,volume。10 MiB、10万本以下。
- JP日足・US1分足。クエリ20本。候補はクエリより過去。結果間も重複除外。
- 重み50/25/15/10、スコア100/(1+加重距離)。将来確率として扱わない。
- 日本語UI、架空データ表示、TradingViewクレジット。

## Review Focus
- 不正カレンダー日付をDateが繰り上げて受理しない。
- 相対価格スケール・ゼロ出来高でも有限の検索スコア。
- 連続インポート・削除で古い検索や保存が復活しない。
- IndexedDBの復元・失敗で画面が使用不能にならない。
- 不正CSVのインポートが現在の正常データを破壊しない。
