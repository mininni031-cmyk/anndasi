# PATTERN LAB Phase 1 実装設計

策定日：2026-10-16
原典：ユーザー提供「PATTERN LAB｜完全無料開発設計書 v3.0」
対象：CSVだけでローソク足と過去類似チャート検索が動くPC向け最小動作品。

## 目的と境界

個人の投資研究・練習用に、直近20本と似た過去のOHLCV区間を確認する。形状類似度は上昇確率ではない。架空データは常に架空と表示する。既存のRICOCHET・mininni・IDEA VAULTには触れず、/workspace/pattern-labを独立プロジェクトとする。

Phase 1では有料API、外部LLM、クラウドDB、証券接続を使用しない。注文・口座・A〜D評価・本格的パターン認識・統計的検証は後続Phaseの未実装機能として文書に明記し、架空の評価結果は表示しない。

## 構成

Next.js、TypeScript、Tailwind CSS、Lightweight Chartsを使用する。データ処理はブラウザ内で完結し、アップロードしたCSVを外部送信しない。依存パッケージの初回取得後はローカル起動で利用できる。PWAや初回アクセスからの完全オフライン配布は対象外。

画面は左70%をメインチャート、右30%を類似結果にする。上部にデータソース・銘柄・市場・時間足・CSV読込を配置し、下部に読込件数、エラー、分析の限界を表示する。日本語UIとし、公開時に必要なTradingViewのクレジットとリンクを設ける。

UI、CSV解析、データ生成、類似度計算、Worker通信、IndexedDB保存を分離する。チャートの生成・更新・破棄は専用コンポーネントで管理する。

## 入力と検証

CSVの必須列は time,open,high,low,close,volume。UTF-8（BOM可）、カンマ区切り、引用符付きフィールド、CRLF/LFを扱う。サンプルCSVを配布する。銘柄・市場（JP/US）・時間足（1d/1m）・通貨（JPY/USD）は読込画面で指定し、データセット単位で保存する。実装対象の初期組合せはJP日足・US1分足とする。

timeは日足ではYYYY-MM-DD、分足ではタイムゾーン必須のISO 8601日時を受け付ける。内部はUTC秒で一意化する。時刻昇順に整列し、重複時刻はエラーとする。価格は有限の正数、出来高は有限の非負数とし、low ≤ open/close ≤ highを満たすことを検証する。不正行は行番号付きで示し、読み込み全体を拒否して現在のデータを保持する。空行は無視する。20本未満の入力は分析不可として理由を表示する。ファイルは10 MiB、10万本までとし、超過は明示的に拒否する。

## 架空データと保存

固定シードの決定的な架空データをJP日足・US1分足で用意する。実銘柄の実績と混同しない名前を付ける。サンプルCSVの出力も同じデータ形式を使う。

取り込んだデータと選択中のデータセットをIndexedDBに保存し、再読込時に復元する。保存失敗時はメモリ上で利用を継続し、保存できなかったことを表示する。保存データを削除する操作を提供する。機密情報・APIキーは保存しない。

## 類似検索

選択中データの末尾20本をクエリにする。検索候補は同じ銘柄・時間足・通貨の過去20本区間に限定し、候補の最終時刻はクエリの最初の時刻より前とする。データを共有する結果の重複を減らすため、採用結果同士の20本区間は重ならないよう順位順に選択する。5件未満なら実件数のみ示す。

価格は各20本の最初の終値からの比率に変換し、区間の価格変動スケールで正規化する。ゼロ変動では明示した下限値を使いゼロ除算を防ぐ。OHLCの全体形状距離50%、最後の足の実体と上下ヒゲの距離25%、最後3本の足の構成距離15%、相対値幅と区間平均に対する相対出来高の距離10%を合成する。出来高がすべてゼロの場合も有限値を返す。各特徴群の平均絶対距離を用い、表示スコアは100 / (1 + 加重距離)とする。確率としての解釈や統計的校正は行わない。

同点は候補の開始時刻昇順で固定する。同じ入力・同じ条件なら同じ結果を返す。検索はWeb Workerで実行し、データ切替時に古い処理の結果を採用しない。

各結果は銘柄、区間日時、形状類似度、20本のミニチャートを表示する。5・10・20本後の騰落率はPhase 2の未来情報制御と統計検証に合わせて追加するため、この段階では表示しない。正式なパターン名も未判定とする。

## 状態とエラー

初期状態、読込中、検索中、検索結果なし、入力エラー、保存エラーを区別する。候補が存在しない場合もメインチャートは使える。利用できない時間足は無効表示し、別の時間足へ単にラベルだけを変更しない。CSVを読み込むとチャート・検索・保存対象を同じデータへ切り替える。

## 検証と完成基準

VitestでCSV正常系と不正値・欠損・重複・時刻解釈、正規化の有限性、同一形状の一致、決定性、クエリとの重複排除、結果間の重複排除を検証する。Playwrightで架空データ表示、サンプルCSV読込、類似結果表示、不正CSVによる既存データ保持、再読込による復元を確認する。TypeScript検査と本番ビルドを通す。

Windows向けREADMEにNode.jsの前提、npm install、npm run dev、localhostのURL、CSV仕様、テスト手順、保存場所と削除方法、Phase 1の制約を記載する。

完成条件は「ユーザーがサンプルCSVを取り込み、ローソク足と再現可能な過去類似検索上位最大5件をローカル環境で確認できること」。PAPER版全体の完成とは区別する。
