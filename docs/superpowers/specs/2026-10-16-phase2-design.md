# Phase 2：研究・リプレイ

原本v3のPhase 2を実装。既存の無料構成・本人限定URLを維持する。

リプレイは完了済みの足の本数をカーソルとし、表示・検出・検索へそのprefixだけを渡す。再生/停止/1本送り/先頭/末尾/スライダー。CSVエクスポートも表示時点までとする。過去候補の20本後までがクエリ開始前に完了するものだけを検索する。

20本の局所極値からW/M、三尊/逆三尊、収束三角形をヒューリスティック判定。形成中・成立確認・否定・判定不可を区別する。ローソク足は十字線と包み足を検出する。閾値は固定の暫定値。現在の終値がネックラインを抜いた場合に成立とする。価格ラインをチャートに表示。

類似候補の5/10/20本後騰落率と、設定した片道コストbpsを往復控除した20本後損益を表示。上位5件集計は選択バイアスを持つため記述統計と明記。独立した期間外検証は、既知の過去区間を時系列60/20/20に分け、各期間内の非重複20+20本区間で同じ固定条件（類似スコア80以上）を適用する。最終期間で条件を調整しない。比較は同じ期間の全候補をランダム時点エントリーの基準とする。平均、損失件数、標本数、平均の95%近似区間を出す。30件未満は根拠不足。信頼区間は独立同分布・正規近似の限界があり、投資確率に使わない。これは現在クエリを固定した期間別検索評価であり、戦略の完全なウォークフォワード検証ではないと明記。

主要検証：未来suffixを変更してもカーソル時点結果が同じ、過去候補の結果がクエリと重複しない、W/M成立/否定、コスト差、短いデータ、再生停止・先頭で未来価格非表示。株式母集団未提供のため生存者バイアスは除去できず警告する。
